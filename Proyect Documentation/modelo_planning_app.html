📚 Planning App · Control de Estudios

Planificación integral para el sistema de récord académico

🎯 Objetivo

  • Gestionar inscripción, evaluación continua, exámenes finales y récord académico.
  • Flujo de trabajo optimizado para roles: Control de Estudios, Docentes y Alumnos.
  • Acceso web responsive (móvil, tablet, escritorio).

🧩 Módulos principales

  • 1 Gestión de Alumnos (inscripción, prelación, agrupación)
  • 2 Evaluación Continua (planificación, transcripción)
  • 3 Exámenes Finales (planificación, notas)
  • 4 Reportes y envíos (correo, impresión)
  • 5 Comunicación (chat institucional)

👥 Roles y permisos

  • Control de Estudios / Dir. Académica – verificación, publicación de notas, gestión total.
  • Docente – planifica evaluaciones, registra notas (con verificación posterior).
  • Alumno – consulta récord, recibe notificaciones, visualiza notas.

🗄️ Base de Datos

  • Motor: PostgreSQL 15 (open source).
  • Tablas con id autoincrementable, historial de transacciones (auditoría).
  • Campos específicos en alumnos: registration_process, continuing_education_program, course_of_study.

🛠️ Tecnologías

  • Framework web: Astro (con React/Vue opcional).
  • Backend: API REST (Node.js / Express) o Astro endpoints.
  • Frontend: HTML5, CSS3, JavaScript (con soporte para PWA).
  • Internacionalización: Español (default), Inglés, Checo.

📋 Reportes y personalización

  • Encabezado: hasta 5 líneas de 80 caracteres + logo.
  • Pie: hasta 3 líneas de 80 caracteres + logo.
  • Tabla report_customization para guardar configuraciones.

📌 Flujo de trabajo clave

  1. Inscripción de alumnos (con prelación opcional).
  2. Agrupación por año y sección.
  3. Docente planifica evaluaciones continuas (con nota mínima y descripción).
  4. Docente transcribe notas → pasa a Control de Estudios para verificación.
  5. Control de Estudios publica notas finales.
  6. Planificación de exámenes finales.
  7. Envío de récord por email e impresión de constancias.

💬 Área común (Chat)

  • Mensajes públicos entre autoridades y docentes.
  • Histórico completo de publicaciones.
  • Notificaciones de resultados, avisos importantes.

🔒 Restricciones clave

  • Docente no publica notas sin verificación de Control de Estudios.
  • Evaluación continua: campo descripción obligatorio.
  • Campos de nombre y apellido limitados a 15 caracteres (dos cada uno).
